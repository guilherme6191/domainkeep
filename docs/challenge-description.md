## Overview

This challenge is designed to evaluate how you build product experiences around technical, trust-sensitive workflows. We're looking at your product judgment, UX craft, technical clarity, TypeScript quality, and ability to make complex setup feel simple.

## Description

Build a product experience that helps a user prove ownership of a domain, understand the verification process, when it fails, and recover from mistakes.

## Requirements

- A fully deployed and accessible online frontend and backend
- Technology stack: TypeScript is required; other technologies are at your discretion
- Be able to claim and prove a domain ownership

## Evaluation Criteria

- Product thinking
- UX quality and interaction design
- Ability to communicate technical setup clearly
- Trust and safety judgment
- Error handling and edge cases
- State modeling
- Code quality, organization, and TypeScript usage
- Full-stack implementation approach
- Thoughtful tradeoffs and scope
- Documentation quality
- Overall polish
